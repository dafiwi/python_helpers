# Python Helpers

This Python program contains multiple little helper functions which allow but are not restricted to data manipulation, data conversion, file operations, data validation, system operations, and obtaining system and datetime information.

The program was tested successfully with Windows 11 and Linux.

## Notes

Run this program in the console to start a menu and then choose a function to execute it.
The function names are self-explanatory. 
A few functions may not work depending on your locale or system settings.

## Tech Stack
- Python 3.14+
- Libraries: csv, importlib.metadata/distributions, locale, mysql-connector-python, openpyxl/load_workbook, openpyxl/Workbook, os, pathlib/ Path, platform, sys, time

## Installation
### Requirements
- Python 3.14 or higher.

git clone https://github.com/dafiwi/python_helpers.git

cd path/to/program-directory

pip install -r requirements.txt

chmod +x python_helpers.py
./python_helpers.py

OR

python3 python_helpers.py

OR

python python_helpers.py
